# 🎵 KLens – Kaiserslautern Explorer

**Live:** https://klens.jasim.dev

KLens is a web-based tool designed to help people explore and understand real data from the City Administration of Kaiserslautern. Inspired by GapMinder, it provides an intuitive interface for discovering insights from public datasets.

The UI is built with React and Bootstrap, visualized via Recharts.

## Spotify Explorer Features

The Spotify Explorer section demonstrates:

1. **Interactive Query Interface** - Run curated sample queries with one click
2. **Real-time Results** - See total hits for each query instantly
3. **Request Inspector** - View the exact Elasticsearch request payload in JSON format
4. **Query Explanations** - Understand the logic behind each query
5. **Data Visualization** - Compare query results with interactive bar charts

### Visualization Details

- Bar charts showing query result counts
- Real-time counters for entries found per query
- JSON viewer displaying the complete Elasticsearch payload
- Active query highlighting
